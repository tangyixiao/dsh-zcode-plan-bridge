ZCode CLI 的模型

稳定版 0.5.2 · 源码预览版 0.6.0-community.5

cordis.patch.yml · L1–13
# dsh-zcode-plan-bridge bundle patch: inserts the plugin row into the profile tree.
# Applied as one layer after dsh-base / dsh-web-app.
# The row id (dsh-zcode-plan-bridge) doubles as the settings group key on the Config page.
#
# name must be the package.json name: the loader resolves it from the profile's
# node_modules by package name (npm install and link: assemblies both take that path).
# Local hot reload (directory assembly, not installed into node_modules): replace name
# with an absolute file:// URL of lib/index.js plus ?v=N -- the loader only re-imports
# the module when the row name changes, and Node ESM keys its cache on the full URL, so
# bump N after editing lib/*.js and re-enable the bundle.
- insert:
    - id: dsh-zcode-plan-bridge
      name: 'dsh-zcode-plan-bridge'

项目里的主要内容

  • 常驻 app-server 会话

    使用 CLI 自身 app-server 的 stdio JSON-RPC 会话。

  • 真实流式协议桥接

    通过流式事件转述模型响应，并处理会话取消。

  • 按 CLI 提供的目录列出模型

    模型清单来自 CLI 与账号状态，并非网站静态承诺。
