## 简体中文

- 工具箱 HTTP 路由先执行宿主同步请求准入和 owner 验证，异步或不可读取的结果安全拒绝。

## English

- Require synchronous host request admission and owner authorization for toolkit HTTP routes; fail closed on asynchronous or unreadable verdicts.
- Retain origin, control-key and scope/revision protections. This version does not include the subsequent session-title generation changes.
