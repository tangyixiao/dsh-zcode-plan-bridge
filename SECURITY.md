# Security policy

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/tangyixiao/dsh-zcode-plan-bridge/security/advisories/new). Do not post credentials, exploit details or private account data in a public issue. If an active credential was exposed, revoke it through its issuer.

Reports should identify affected versions, a minimal redacted reproduction and impact. Supported compatibility is declared by the actual package and release notes; there is no blanket guarantee for future host releases. This independent community project does not operate the upstream product or account service.
