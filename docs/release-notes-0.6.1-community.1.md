# 0.6.1-community.1

Publishes the current qualified stable source as an explicitly selected community preview. It includes the current black README banners, character artwork and complete package documentation. Runtime requirements, account/profile formats and supported hosts remain unchanged.

Install the exact preview with `dsh plugin --profile web add dsh-zcode-plan-bridge@0.6.1-community.1`. This source branch stays separate from stable main; npm latest remains 0.6.1. The GitHub release is marked prerelease and does not replace the stable latest release.

Source CI, the built preview version, npm channel/tag metadata, exact downloaded artifact hashes and release assets are verified independently before updating the preview index.
